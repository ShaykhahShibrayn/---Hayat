# AGENTS.md

## General Rules

- Build a clean, modern, and scalable application.
- Use reusable and well-organized components.
- Keep the code clean, readable, and maintainable.
- Follow responsive design principles for desktop and mobile.

## UI Guidelines

- Use a medical-inspired design.
- Primary colors: White (#FFFFFF) and Red (#C62828).
- Use rounded cards, soft shadows, and smooth animations.
- Include meaningful icons throughout the interface (blood drop, hospital, heart, user, campaign, notifications, etc.).
- Maintain a consistent and elegant UI/UX across all pages.
- All interfaces must support Arabic (RTL).

## Project Rules

- Keep frontend and backend separated.
- Use clear folder organization.
- Write reusable code and avoid duplication.
- Do not implement features that are outside the PRD unless requested.
- Always preserve the existing project structure and avoid breaking previously implemented features when adding new functionality.
