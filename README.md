## Project Overview

Hayat is a web-based platform designed to simplify blood donation management by connecting blood donors, patients’ representatives, hospitals, and organizations conducting blood donation campaigns in one centralized platform.
The platform helps users discover verified blood donation requests and campaigns while allowing hospitals and organizations to manage their needs efficiently. Medical eligibility for blood donation remains the responsibility of healthcare professionals.

## How to Use the Application

## Donor

- Register as a blood donor.
- View available blood donation requests.
- Browse voluntary donation campaigns.
- Express willingness to donate.

## Patient Representative

- Create a blood donation request.
- View and manage submitted requests.

## Hospital

- Publish blood shortage requests.
- Manage donation requests.
- Update request status.

## Organization / Campaign

- Create blood donation campaigns.
- Manage campaign details.
- View volunteer registrations.
